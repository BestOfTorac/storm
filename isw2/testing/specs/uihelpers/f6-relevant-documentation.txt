  225: ### /api/v1/supervisor (GET)
  226:
  227: Returns summary for a supervisor by id, or all supervisors running on a host.
  228:
  229: Examples:
  230:
  231: ```no-highlight
  232:  1. By host: http://ui-daemon-host-name:8080/api/v1/supervisor?host=supervisor-daemon-host-name
  233:  2. By id: http://ui-daemon-host-name:8080/api/v1/supervisor?id=f5449110-1daa-43e2-89e3-69917b16dec9-192.168.1.1
  234: ```
  235:
  236: Request parameters:
  237:
  238: |Parameter |Value   |Description  |
  239: |----------|--------|-------------|
  240: |id   	   |String. Supervisor id | If specified, respond with the supervisor and worker stats with id. Note that when id is specified, the host argument is ignored. |
  241: |host      |String. Host name| If specified, respond with all supervisors and worker stats in the host (normally just one)|
  242: |sys       |String. Values 1 or 0. Default value 0| Controls including sys stats part of the response|
  243:
  244: Response fields:
  245:
  246: |Field  |Value|Description|
  247: |---	|---	|---
  248: |supervisors| Array| Array of supervisor summaries|
  249: |workers| Array| Array of worker summaries |
  250: |schedulerDisplayResource| Boolean | Whether to display scheduler resource information|
  251:
  252: Each supervisor is defined by:
  253:
  254: |Field  |Value|Description|
  255: |---	|---	|---
  256: |id| String | Supervisor's id|
  257: |host| String| Supervisor's host name|
  258: |uptime| String| Shows how long the supervisor is running|
  259: |uptimeSeconds| Integer| Shows how long the supervisor is running in seconds|
  260: |slotsTotal| Integer| Total number of worker slots for this supervisor|
  261: |slotsUsed| Integer| Number of worker slots used on this supervisor|
  262: |schedulerDisplayResource| Boolean | Whether to display scheduler resource information|
  263: |totalMem| Double| Total memory capacity on this supervisor|
  264: |totalCpu| Double| Total CPU capacity on this supervisor|
  265: |usedMem| Double| Used memory capacity on this supervisor|
  266: |usedCpu| Double| Used CPU capacity on this supervisor|
  267:
  268: Each worker is defined by:
  269:
  270: |Field  |Value  |Description|
  271: |-------|-------|-----------|
  272: |supervisorId | String| Supervisor's id|
  273: |host | String | Worker's host name|
  274: |port | Integer | Worker's port|
  275: |topologyId | String | Topology Id|
  276: |topologyName | String | Topology Name|
  277: |executorsTotal | Integer | Number of executors used by the topology in this worker|
  278: |assignedMemOnHeap | Double | Assigned On-Heap Memory by Scheduler (MB)|
  279: |assignedMemOffHeap | Double | Assigned Off-Heap Memory by Scheduler (MB)|
  280: |assignedCpu | Number | Assigned CPU by Scheduler (%)|
  281: |componentNumTasks | Dictionary | Components -> # of executing tasks|
  282: |uptime| String| Shows how long the worker is running|
  283: |uptimeSeconds| Integer| Shows how long the worker is running in seconds|
  284: |workerLogLink | String | Link to worker log viewer page|
